# ml/datasets/

**No data lives here.** Research data is stored in `VSL_DATA_ROOT`, which is always **outside the repository** (default: the platform user-data directory on the Windows laptop). This keeps recordings and landmarks out of git and away from tools that index the repo.

This folder's contents are gitignored as a second safety net. See [docs/DATASET_AND_ANNOTATION.md](../../docs/DATASET_AND_ANNOTATION.md) for consent, manifest format, storage, retention and deletion.
