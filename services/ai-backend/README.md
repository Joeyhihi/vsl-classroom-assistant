# vsl-backend

FastAPI backend for VSL Classroom Assistant. Binds to `127.0.0.1` only.

```bash
uv run python scripts/run_backend.py          # from the repo root
uv run python scripts/run_backend.py --mock   # force mock model mode
```

Contracts: [docs/API_CONTRACTS.md](../../docs/API_CONTRACTS.md). Architecture: [docs/ARCHITECTURE.md](../../docs/ARCHITECTURE.md).
